FROM product_events
WHERE signup_at >= now() - INTERVAL 7 DAY
GROUP BY user_id

   AND countIf(event = 'data_inserted') = 0
   AND max(ts) < now() - INTERVAL 48 HOUR

Get to value, then to paid

Triggered by what the user does in the product.

01
SignupWelcome by use case: analytics, observability, real-time apps.
02
First serviceNudge only if stalled: service_created, no data yet.

DAYS 31–60

  • Launch use-case onboarding and the stalled-user nudge, with a holdout.
  • Align emails with in-product messages so they don't overlap.
  • Set up the lifecycle dashboard for PLG and SLG.
  • Start the testing roadmap.

DAYS 61–90

Build nurture

  • Launch persona streams for the sales-led funnel.
  • Trial-end and conversion journeys based on usage.
  • First monthly lifecycle report: what worked, what's next.
  • Roadmap for the next two quarters.
